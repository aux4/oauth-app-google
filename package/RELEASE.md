# aux4/oauth-app-google

Renamed from `aux4/google-oauth-app` into the `oauth-app*` family (alongside
`aux4/oauth-app-x` and the combined `aux4/oauth-app`). Same package: a public,
one-click-deployable Google OAuth service. Set `GOOGLE_CLIENT_ID` /
`GOOGLE_CLIENT_SECRET` (+ optional `GOOGLE_SCOPES`) and point your CLI at it.
